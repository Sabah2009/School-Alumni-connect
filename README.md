
# 🎓 School Alumni Connect
### Connecting Generations, Building Futures.

School Alumni Connect is a web-based platform designed to create a digital connection between former students and the school community. It provides an organised environment where users can explore alumni profiles, discover professional backgrounds, submit requests, register for events, and stay updated with community activities.

The platform focuses on making alumni networking and community interaction simple, accessible, and organised.

---

# ✨ 12 Key Features

## 1. User Login Interface
The platform provides a dedicated login page that acts as the entry point to the website.

- Provides a clean and user-friendly login interface.
- Allows users to enter their login details.
- Provides navigation to the main dashboard.
- Creates a structured starting point for accessing the platform.

## 2. Interactive Dashboard
The dashboard serves as the central overview of the entire platform.

- Displays important community statistics.
- Shows the total number of alumni members.
- Displays event registration counts.
- Shows the number of pending requests.
- Provides quick access to different website sections.
- Presents announcements and upcoming activities.

## 3. Dynamic Alumni Directory
The Alumni Directory provides an organised collection of alumni profiles.

- Displays available alumni information in a structured layout.
- Shows alumni names, graduation years, professions, companies, and other profile details.
- Makes it easier for users to explore the alumni community.
- Automatically displays newly added alumni records.

## 4. Alumni Search Functionality
The platform includes a search feature to help users quickly find specific alumni.

- Search alumni using their names.
- Find profiles using professional information.
- Search through available company details.
- Reduces the time required to locate a particular profile.

## 5. Advanced Alumni Filtering
Users can narrow down the displayed alumni records using filters.

- Filter alumni according to graduation year.
- Filter alumni according to profession or professional category.
- Combine search and filtering to find relevant profiles.
- Makes browsing a larger alumni directory more convenient.

## 6. Add New Alumni Profiles
The website allows users to add new alumni records to the directory.

- Enter the alumnus's name.
- Add graduation year.
- Enter professional information.
- Add company or organisation details.
- Select the relevant profile status.
- Save the new profile directly to the directory.

## 7. Edit and Delete Alumni Records
The directory supports basic record management.

- Edit previously saved alumni information.
- Update graduation year and professional details.
- Delete records that are no longer required.
- Automatically refresh the directory after changes.
- Keeps the displayed information organised and up to date.

## 8. Automatic Dashboard Statistics
The dashboard is connected to the data saved in the Alumni Directory and Requests section.

- Automatically calculates the total number of alumni.
- Updates the alumni count when a new profile is added.
- Reflects changes when an existing profile is edited or deleted.
- Displays the number of saved event registrations.
- Displays the number of pending requests.
- Uses browser Local Storage to retrieve the latest saved information.

## 9. Online Request Submission
The Requests section provides a form through which users can submit different types of requests.

- Enter personal details such as name and email.
- Select the type of request.
- Choose a priority level.
- Provide a detailed request description.
- Submit the request through the website.
- Automatically generates a unique request ID.
- Saves submitted information for later viewing.

## 10. Request Tracking and Management
The platform provides a section to view submitted requests.

- Displays submitted requests in an organised table.
- Shows request identification numbers.
- Displays request types and submission dates.
- Shows the current request status.
- Highlights pending requests.
- Retains saved request information even after refreshing the page.

## 11. Upcoming Events and Registration Interest
The website provides information about upcoming alumni activities and allows users to register their interest.

- Displays upcoming events with dates and locations.
- Provides event information such as Annual Alumni Reunion, Career Guidance Workshop, and Alumni Mentorship Day.
- Allows users to select an event.
- Collects registration details through an online form.
- Saves event registration interest.
- Prevents duplicate registrations for the same email address and event.

## 12. Persistent Data Storage and Cross-Page Integration
The platform uses JavaScript and browser Local Storage to maintain information across its different pages.

- Stores alumni records using Local Storage.
- Saves submitted requests and event registration interests.
- Retains information after refreshing the website.
- Connects the Alumni Directory with the Dashboard.
- Connects the Requests section with the Dashboard.
- Updates relevant dashboard statistics using saved records.
- Allows different pages to access the same stored information within the same browser and website origin.

| Section | Main Purpose |

| Alumni Directory | Search, filter, and manage alumni profiles |
| Requests | Submit requests and register interest in events |

---

# 🛠️ Technologies Behind the Platform

- **HTML5:** Structures the different pages and forms.
- **CSS3:** Provides the website's visual design and layout.
- **JavaScript:** Handles search, filtering, record management, form submissions, and dynamic statistics.
- **Local Storage:** Saves and retrieves information within the browser.

---

# 📌 How the Platform Works

1. Users enter the platform through the login interface.
2. The dashboard provides an overview of community information.
3. Users can explore, search, filter, add, edit, and delete alumni profiles.
4. Users can submit requests and register interest in upcoming events.
5. JavaScript saves the submitted information in browser Local Storage.
6. The dashboard reads the saved information and updates its statistics accordingly.

**Note:** The current version uses browser-based Local Storage rather than a central database. Therefore, saved records are available in the same browser and website origin, but are not automatically synchronised between different users or devices.
